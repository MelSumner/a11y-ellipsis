Truncation Component: Examples

Live versions of the code samples in the documentation

Each example sits in a frame you can resize, either by dragging its lower corner or with its width slider. Hover over or focus a truncated value to see the full text. These are plain HTML and JavaScript ports of the Ember code, using tippy.js for tooltips.

Reveal Button

Plain text that doesn't fit shows a faded copy and a ⋯ button. The button's accessible name and its tooltip are the full value. See The component.

Link

The link itself is the clip. It keeps the browser's own ellipsis and shows its tooltip only while its text is clipped. See Reveal Hosts.

Link Host with Overflowing Text

Button with an icon

The label span is the clip, marked data-truncation-clip. No text argument is passed, so the tooltip reads the label when it shows. The icon keeps its size with flex-shrink: 0.

File upload

The visually hidden input takes focus, so it hosts the tooltip. The file name it reveals sits in its label. A long file name is preselected; choose another file to replace it. Following Rule 9, the tooltip mounts beside the label rather than inside it.

Select trigger

A button-based select. The selected value is the clip, and the button is the host. The tooltip doesn't show while the listbox is open (aria-expanded="true").

Menu button with two lines

The wrapper is the clip, and each line inside it is a block. The tooltip shows one row per line, read at the moment it shows.

Locked host with a reason

An optional extension. While locked, the button stays focusable with aria-disabled="true". Its tooltip shows the reason even when nothing is clipped, and shows "value: reason" when the value is clipped too. See Locked hosts.

Table cells

Text cells use a Reveal Button. Link cells make the link a Reveal Host, with each stacked line as its own clip. The name cell is a link where the record can be opened and plain text where it can't. The last column is a visually hidden copy, so it stays plain text. See Consumers.

Title with identifier

The identifier always stays whole. Inside a link, the title can only clip, because the link is the host. Outside a link, the title gets its own Reveal Button.

Grouped values

A cell that stands for several values always shows the ⋯ button, which lists every value. The first name clips under it. A group with a single item uses a plain <Truncation>.

Name label with translated copy

The translated sentence is split around a placeholder character, so the name can truncate wherever the language puts it: at the start, in the middle, or at the end.

No scroll timeline (fallback)

Without scroll-driven animations, the plain text wraps anywhere, so nothing is lost. Browsers can't turn @supports off on demand, so the frame below is a simulation: it applies the same fallback rules through a class.
